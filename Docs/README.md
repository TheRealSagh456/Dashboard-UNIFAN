# Documentação do Dashboard UNIFAN

Esta pasta reúne as definições funcionais, técnicas e organizacionais do projeto.
Os documentos devem representar o comportamento atual esperado do sistema e ser
atualizados sempre que uma decisão relevante for tomada.

## Convenções

- A estrutura atual do repositório utiliza as pastas `Frontend`, `Backend` e `Docs`.
- O npm é o gerenciador de pacotes oficial do frontend e do backend.
- Decisões ainda não confirmadas devem ser registradas como pendentes, sem serem
  tratadas como requisitos definitivos.
- Alterações nos contratos da API devem ser documentadas antes ou junto da
  implementação.
